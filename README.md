# Ember & Oak Café — Client Website Demo

> **Specialty coffee, handcrafted plates, and quiet moments in the heart of Fort Kochi.**

An editorial, client-facing website prototype created for **Ember & Oak Café**. Designed with a sophisticated contemporary aesthetic inspired by coffee, wood, cream, parchment, and charcoal.

---

## ☕ Design System & Aesthetic

- **Palette**: Warm neutrals (`#FAF7F2` cream, `#F4EFEA` parchment, `#141210` espresso charcoal, `#C47A47` roasted amber).
- **Typography**: Cormorant Garamond (Editorial serif headings) paired with Plus Jakarta Sans (Clean modern sans-serif UI).
- **Imagery**: 11 authentic, high-resolution bespoke café photographs showcasing barista craft, latte art, culinary plates, and heritage architecture.
- **Interactions**:
  - Sticky frosted navigation bar with live status indicator.
  - Interactive menu filter tabs and real-time menu search.
  - Signature Drink interactive customizer (temperature & milk pairings).
  - Responsive masonry gallery with categorized filter tabs and full-screen lightbox modal.
  - Table booking and transit directions modals with toast confirmations.
  - Mobile slide-out drawer menu with animated hamburger toggle.

## 📁 Repository Structure


## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/veyrastudioads-glitch/ember-and-oak-cafe.git

# Navigate to the folder
cd ember-and-oak-cafe

# Start the dev server
npm start
```

Then visit **`http://localhost:3000`** in your browser.
